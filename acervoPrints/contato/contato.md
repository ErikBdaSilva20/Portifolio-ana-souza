# Tela de Contato

Essa tela é feita para quem deseja falar diretamente com a Ana Julia, seja para propor um trabalho, tirar uma dúvida ou fazer um convite.

Ela conta com um formulário simples, onde a pessoa preenche o nome, o email, o número de WhatsApp, escolhe o assunto da mensagem, escreve o que precisa e ainda pode indicar o melhor horário para ser contatada.

Além do formulário, existe também um botão que leva direto para uma conversa no WhatsApp, para quem prefere uma resposta mais rápida sem precisar preencher nada.

No fim das contas, essa tela existe para facilitar ao máximo o primeiro contato entre a pessoa interessada e a Ana.
