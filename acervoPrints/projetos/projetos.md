# Tela de Projetos

Essa tela reúne todos os trabalhos feitos pela Ana Julia em um só lugar, como se fosse um arquivo completo do portfólio dela.

Existe um menu de filtros no topo, com opções como Branding, Comunidade, Extensão e Estratégia, que permite a pessoa escolher ver apenas os projetos de um certo tipo, sem precisar rolar a tela toda procurando.

Cada projeto aparece como um cartão, com uma imagem, um pequeno texto explicando do que se trata e algumas etiquetas indicando o tema do trabalho. Ao clicar em um desses cartões, a pessoa é levada para a página com os detalhes completos daquele projeto.

Essa tela serve para mostrar, de forma organizada, a quantidade e a variedade de trabalhos que a Ana já desenvolveu.
